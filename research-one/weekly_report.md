# 组会周报：面向边缘大模型的按需读写参数化记忆机制

## 1. 本周工作概述

本周围绕论文 **MLP Memory: A Retriever-Pretrained Memory for Large Language Models** 及相关方向进行了进一步调研和思考。该方向的核心思想是将外部检索器中的知识访问能力压缩到参数化模块中，使大模型在推理时不必频繁访问外部文档，也能获得类似 RAG 的知识增强效果。结合我们关注的边缘智能和移动计算场景，本周重点思考了如何将参数化记忆机制改造成适合端侧设备运行的高效长期记忆系统。

## 2. 研究背景与问题

现有 RAG 方法能够灵活访问外部知识，但在端侧设备上会带来较高的检索延迟、内存占用和能耗开销；而 LoRA、MLP Memory 等参数化方法推理效率较高，但通常是静态的、全局的，存在始终激活、难以更新、难以删除等问题。特别是在手机、边缘节点等资源受限环境中，模型不应该对每个 token 都访问记忆，也不应该将所有新知识都写入参数。因此，我们希望研究一个更适合端侧部署的问题：**边缘设备上的大模型应该如何判断什么时候读取参数记忆，以及什么时候将外部知识写入参数记忆。**

## 3. 相关工作参考

目前主要参考了六类核心工作。**MLP Memory** 证明了检索器的知识分布可以被蒸馏到 MLP 参数记忆中，但其记忆模块始终激活，不适合端侧。**Memory Layers at Scale** 说明稀疏激活的记忆层可以有效提升事实知识容量，为我们设计稀疏记忆专家提供了参考。**Doc-to-LoRA** 探索将文档快速编译成 LoRA 参数，说明外部知识可以被转化为可插拔参数模块。**Titans** 使用 surprise 信号进行测试时记忆，为判断哪些信息值得记忆提供了启发。**UniMem** 研究情景记忆到参数记忆的逐步固化机制，说明新知识可以先存入外部记忆，再将高频稳定知识固化为参数。**MobileRAG** 则从系统角度研究端侧 RAG 的延迟、内存和能耗问题，可作为我们后续端侧实验的重要 baseline。

## 4. 初步研究思路

我们计划将研究问题收敛为 **面向边缘大模型的按需读写参数化记忆机制**。该思路包含两个相互配合的 idea。

第一个 idea 是 **按需读取的稀疏参数记忆**。现有 MLP Memory 在每个 token 上都会运行记忆模块，但实际生成中只有实体、时间、地点、长尾事实或模型不确定的位置才真正需要外部知识。因此，我们考虑设计一个轻量级 Read Router，根据 hidden state、模型输出熵、logit gap、实体信息等信号判断当前是否需要激活记忆。如果不需要，则直接使用基础模型输出；如果需要，则只激活少量 micro-MLP 或 micro-LoRA memory atoms，从而降低端侧推理时的计算和能耗开销。

第二个 idea 是 **资源感知的记忆写入与固化机制**。端侧设备会不断产生新的本地知识，例如用户文档、历史交互和场景信息，但不是所有知识都值得写入参数。我们考虑让新知识先进入本地向量库，系统持续统计其访问频率、回答收益、稳定性、隐私风险和设备状态。当某些知识高频、稳定且参数化后能够明显减少检索开销时，再在设备空闲或充电阶段将其固化为 micro-LoRA 或 memory atom。如果知识过期、冲突或用户删除，则可以卸载对应模块，回退到可追溯的外部记忆。

这两个 idea 共同解决一个完整问题：**Idea 2 负责决定哪些知识值得写入参数记忆，Idea 1 负责决定写入后的记忆什么时候被读取。** 二者结合后，可以构成一个端侧长期记忆闭环，在准确率、延迟、能耗、存储和隐私之间取得更好的平衡。

## 5. 初步实验设计

实验计划先控制在较低成本下完成验证。模型方面可选用 Qwen2.5-0.5B 或 Qwen2.5-1.5B 作为基础模型，冻结主模型参数，只训练 router 和小型 memory modules。数据方面，先使用 Natural Questions、TriviaQA、HotpotQA 等知识问答数据验证记忆增强能力，再构造一个流式知识更新数据集，包含稳定知识、高频知识、低频知识、过期知识和错误知识，用于测试记忆固化与删除机制。

对比方法包括 Base LLM、本地 RAG、始终激活的 Dense MLP Memory、静态 LoRA、只使用按需读取的方法、只使用资源感知写入的方法，以及完整方法。评估指标包括 QA 的 EM/F1、推理延迟、tokens/s、峰值内存、参数记忆激活率、本地检索次数下降比例、写入次数、过期知识错误率和删除延迟等。核心目标是验证：在端侧资源受限条件下，是否能够以较低的记忆激活率和较少的检索次数，获得接近 RAG 或 Dense Memory 的知识增强效果。

## 6. 后续计划

下一步计划首先完成 Idea 1 的最小实验原型，即构建本地 RAG teacher，训练一个小型 micro-MLP/micro-LoRA memory，并加入 Read Router 验证按需激活是否有效。随后再构造流式知识更新数据，验证资源感知写入策略能否减少无效固化、降低过期知识错误，并与按需读取机制形成端到端闭环。短期目标是先得到一组清晰的准确率-效率 trade-off 结果，为后续进一步扩展为完整论文方案打基础。
